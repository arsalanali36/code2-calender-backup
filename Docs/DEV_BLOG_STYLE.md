# Dev Blog Style Rules

Last updated: 2026-03-07

1. Every blog post must have an `emoji` field.
2. Never use text placeholders like `BLOG`, `TL`, `UP` in `emoji`.
3. Use a real emoji character in the sidebar entry.
4. Keep emoji meaningful to the post theme.
5. Before publishing, verify all entries in `data/dev-blog.json` have valid emoji.
6. In post body, section headings (`<h3>`) should include a visible emoji (emoji char or HTML entity like `&#x1F680;`).
7. Prefer HTML emoji entities in body text to avoid Windows encoding/mojibake issues.
